How the radar values a launch — the model, in plain words

Each protocol's implied value is its TVL times a multiple, adjusted for momentum, age, and chain breadth:

implied value = TVL × category multiple × growth factor × age factor × breadth factor

  • Category multiple. The median market-cap-to-TVL ratio of the protocols in the same category whose token already trades, taken from this same snapshot. Categories with too few traded comparables use the global median. No name list, no hand-picked multiple.
  • Growth factor. The protocol's 7-day TVL change, capped, so one wild week cannot dominate: shrinking protocols are discounted, growing ones rewarded.
  • Age factor. Days since DefiLlama began tracking the protocol with no token recorded, saturating after about two and a half years: value accrues with a track record.
  • Breadth factor. A small premium per extra chain, capped: more chains reach more users.

The board holds every protocol that records no token — no CoinGecko id, no ticker, no market cap in the record. The 40-protocol watchlist is the floor, never the ceiling: most rows sit below it, and those are the early finds. Protocols whose token already trades appear only as calibration comparables below, never on the board.

Token Radar reads a sealed DefiLlama snapshot and derives everything from its figures. “Records no token” means the snapshot's record carries no token — it is not proof that none exists. Implied values are this entry's own claim, never a prediction that a token will launch, and farm plans are starting points: verify every contract address before you approve anything.
